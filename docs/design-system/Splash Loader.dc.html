Splash loader

The waveform is drawn from the last track you played, so it is different each launch. When loading finishes, the spinning record flies into deck A and the app appears underneath, without a cut. Load an audio file to try it with your own track; it is remembered for the next restart.

Usage

<om-splash id="splash" style="position:fixed;inset:0"></om-splash>

const s = document.getElementById('splash');
s.waveform = settings.lastTrackPeaks;     // cached on last load; omit on first launch
s.status = 'Starting audio engine';
await audio.init();      s.progress = 0.3;
s.status = 'Loading library';
await library.scan(p => s.progress = 0.3 + p * 0.7);
s.complete({ handoffTo: deckA.platterEl }); // record flies into deck A
s.addEventListener('om-splash-done', e => {
  deckA.platter.startAt(e.detail.angle);  // keep spinning from the same angle
  s.remove();
});

// when a track loads in the app, cache its peaks for next launch
settings.lastTrackPeaks = OMSplash.peaks(audioBuffer);

Peaks are a small array (400 numbers), so cache them with the session rather than decoding audio at launch. Setting waveform mid-load morphs the bars. Without handoffTo, complete() brakes the record to the icon position and fades as before.
