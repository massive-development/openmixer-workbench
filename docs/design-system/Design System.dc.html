OpenMixer design system v2

One faceplate instead of nested cards. Three columns (deck A, mixer, deck B) run top to bottom, and deck B mirrors A. Hardware-style faders with a dB scale, centre-detent EQ knobs, no glows. This version replaces the first.

States

With no glow, an active control is told apart by fill, edge and a word, never by colour or light alone. Each state below is a fixed rule: tonal steps for hover and press, a deck-hue tint plus edge for on, a dashed edge for disabled and error, a 2px ivory ring for keyboard focus. Signal red stays reserved for the playhead, record and clip.

Panel tone, dashed edge, no hover. The dashed edge is the cue, not colour.

On state plus a "LOCK" word in the deck hue, so lock is readable without colour.

Segments fill in ivory. Top segment stays dark.
Meter, clipping
CLIP
Top segment and the word CLIP in signal red; held until reset. Recording and the playhead share this red.
