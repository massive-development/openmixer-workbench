Start/Install on Linux

Install on Linux

OpenMixer builds from source with Cargo. This takes about ten minutes on a recent machine.

Alpha

v0.1.0-alpha.1 is a source snapshot. Audio and display behaviour on real hardware hasn't been verified yet.

1. Install dependencies

You need a C toolchain, pkg-config and the ALSA headers.

Shell · Ubuntu / DebianCopy
$ sudo apt install build-essential pkg-config libasound2-dev

2. Install Rust

Use rustup to get the stable toolchain. OpenMixer tracks the latest stable release.

ShellCopy
$ curl https://sh.rustup.rs -sSf | sh

3. Build and run

ShellCopy
$ git clone https://github.com/massive-development/openmixer.git
$ cd openmixer
$ cargo run --release -p openmixer

Add --features om-engine/ffmpeg to decode formats the built-in decoders don't read.

If you hear dropouts

OpenMixer asks for a 256-frame buffer by default. On slower machines, raise it under Settings, Audio. The value you choose there always wins.

v0.1.0-alpha.1

First alpha. Stems, an ffmpeg fallback, a second colour scheme and plugin ABI 2.

Heads up

This is a source snapshot, not a finished alpha. Listening checks for stems and Automix (A4, A5) and native audio and display passes (A8 to A11) are still open, so behaviour on real hardware is unverified.

Stems
  • htdemucs.onnx export that works, with the Rust pipeline checked against Demucs#207
  • The onnx CI job now blocks merges#208
Decoding
  • ffmpeg decode fallback for decks, stems and analysis, behind the optional ffmpeg feature#123
Interface
  • Harbour Night, a second colour scheme#124
  • Platter, toggles, settings chips and the debug column move onto LookAndFeel#122
  • Meter scale spacing and two-line sampler pad labels#127
  • Headless paint and layout tests#125
Plugins
  • C ABI 2: prepare, parameters and contained panics. No third-party plugin has been loaded yet#126
Latency and CPU
  • 256-frame device buffer by default, with output latency reported. A buffer size set in Settings still wins#213
  • Faster seeks: the decoder polls at 200 µs and starts with a 256-frame chunk#213
  • Cheaper effects: table-based phaser, no per-sample division in tape stop and delay, flat EQ bands skipped#213
Project and CI
  • ADR 0006 on controller map provenance#209
  • Issue-driven progress heatmap in the README#210
  • Soak test track length fix#211
  • CI pinned to ubuntu-24.04 and checkout v5#214

Known gaps

Jog wheels and encoders

Relative and toggle MIDI messages build a full engine snapshot per message.

Denormals

No FTZ/DAZ handling yet; the workspace forbids unsafe code.

Platforms

Linux only in CI. macOS and Windows return in the porting phase.

Binaries

Source only. There is no binary build workflow yet.
