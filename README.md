# openmixer-workbench

Planning, research and tooling for [OpenMixer](https://github.com/massive-development/openmixer).
Nothing here is needed to build or run the app.

- `docs/superpowers/` specs and implementation plans
- `docs/design/`, `docs/design-system/` faceplate and brand design work
- `docs/spikes/`, `spikes/` throwaway experiments (cpal, GPUI, time-stretch) and their decision log
- `docs/screenshots/` captured UI reviews
- `docs/PROGRESS.md`, `docs/progress.json` progress tracking
- `.agents/`, `agents.md`, `TODO.md` AI-agent guidance and working notes
- `tools/` heatmap and graph helper scripts

History was extracted from the app repository, so `git log` here shows the original commits.
